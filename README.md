# Brandita — work

Case studies and landing pages for Brandita for Digital Services, Cairo.

- `case-studies.html` — case stories (English). Ad link to a playing story: `case-studies.html#play-<case id>`; full case: `#<case id>`
- `case-studies-ar.html` — Arabic edition
- `for-stores.html` — landing page for online stores (`#fashion`, `#beauty`, `#food`, `#electronics`)
- `client-case.html` — single client case (`#nour`, `#kahwa` are samples)

Built from `Brandita/BD-Assets/interactive/` by `build-site.ps1`; copy the rebuilt `site/` pages here to update.
Every case except Lazoomi is a marked sample with placeholder figures.
